# Forward-Forward-CNN-with-Learnable-Goodness-Heads
Code for "Eliminating Label Overlays in Forward-Forward CNNs via Learned Goodness Heads" — biologically plausible alternative to backpropagation. PyTorch implementation of ClassicFF-CNN with parametric goodness heads. Beats prior FF-CNN methods on CIFAR-10 (79.26%), CIFAR-100 (52.58%), FashionMNIST (91.22%).
